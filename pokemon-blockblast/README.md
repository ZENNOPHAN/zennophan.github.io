# PokéBlast — Block Blast Pokémon Edition

🎮 **Live Game:** [https://zennophan.github.io/pokemon-blockblast/](https://zennophan.github.io/pokemon-blockblast/)

## Cách chơi
- **Kéo** các khối từ khay bên dưới lên lưới 9×9
- **Xóa** hàng ngang hoặc cột dọc đầy để ghi điểm
- **Chain** nhiều lần liên tiếp để kích hoạt COMBO x nhân điểm
- Nhấn **R** để restart nhanh

## Tính năng
- 8 loại Pokémon Type: Fire, Water, Grass, Electric, Psychic, Poison, Ice, Dragon
- Hệ thống Level & XP
- Pokémon Partner thay đổi theo level
- Combo multiplier
- Particle effects & Flash animation
- Lưu điểm cao (localStorage)
- Hỗ trợ cảm ứng (mobile/tablet)

## Deploy
Game chạy hoàn toàn bằng HTML/CSS/JS thuần — không cần server.
